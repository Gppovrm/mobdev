# ЛР3 — мобильное приложение для общения в каналах

Платформа: Dart + Flutter, Android

Запуск: `flutter run`

## Состояние

- SessionStore (вход/выход/401), HomeStore (каналы, выбранный чат, картинка), ChatStore (сообщения канала, пагинация, отправка)
- Состояние живёт выше экранов, поэтому поворот ничего не перезагружает. `HomeStore` создаётся под конкретную сессию: после выхода он закрывается вместе со всеми чатами, и ответы незавершённых запросов никуда не попадают

## Хранение черновиков

- Токен и имя пользователя — `flutter_secure_storage`. Пароль нигде не сохраняется.
- Черновики — `shared_preferences`, ключ «пользователь + канал». Сохраняются при каждом изменении и восстанавливаются после поворота, смены чата и перезапуска. При выходе удаляются данные только текущего пользователя

## Ошибки отправки

- После нажатия «Отправить» поле очищается, а сообщение появляется в ленте со статусом «Отправляется», затем «Отправлено» или «Не удалось подтвердить отправку»;
- Пока сообщение не подтверждено, его текст лежит на диске, поэтому не теряется даже при перезапуске;
- Автоповторов нет. «Повторить» сначала предупреждает, что сообщение могло уже дойти, и обновляет тот же элемент. «В редактор» возвращает текст в поле ввода;
- После успеха сообщение связывается с серверным `id` и не дублируется при обновлении истории;
- 401 на защищённом запросе один раз завершает сессию и открывает экран входа.
